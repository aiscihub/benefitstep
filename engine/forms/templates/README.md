# Official templates are not redistributed in this package

The official PDF pages were read through the research browser on October 4, 2026. Their original binary files could not be retrieved by this build environment. Do not treat the binding templates as calibrated maps or a substitute for the official forms.

Obtain the official files listed in `../registry.json` and save them locally. `python tools/pdf_template.py inspect ...` inventories the actual fields, geometry, page count and hash. An independent reviewer must compare the native form against the question inventory, bind fields and protect signature/office-use regions before approval. The included synthetic test form is not an application and must never be filed.

CF285: 18 pages, edition 8/21. SAWS2PLUS: 29 pages, edition 4/15. CCFRM604: 44 pages, revision 09/2025. Recheck the agency source before deploying; page count alone does not establish an edition or authenticity.
