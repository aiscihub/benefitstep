## Detailed description

Prepare your benefits application package with BenefitStep, an independent helper for California residents exploring CalFresh and Medi-Cal.

• Answer a few starting questions for an initial reference check.
• Add your PDFs, images or text files. BenefitStep suggests document types and extracts supported details for you to review.
• Use Package Doctor to identify selected inconsistencies, duplicates and missing context.
• Reuse compatible confirmed details in CF285 and Medi-Cal application drafts.
• Preview and download unsigned PDFs or an application package with items still needing attention.

Documents and answers are processed locally in the extension. BenefitStep does not upload them to a developer server or cloud AI service. Work is temporary; download your package to retain it. Downloaded files remain on your device until you delete them.

Try the built-in fictional demo without providing personal documents. Demo questionnaires are labeled separately from live document-recognition results, and fictional PDFs must not be submitted.

BenefitStep is not affiliated with BenefitsCal, CDSS, DHCS or any government agency. Initial checks are not eligibility decisions. It does not read or fill the BenefitsCal website or submit applications. Official-form field mapping is still under independent review: inspect every generated draft, complete missing items and signatures, and use the appropriate official submission route.

Requires desktop Chrome 138 or later. Document recognition varies with document quality; on-device AI availability varies by Chrome/device. A local text reader supports a subset of documents when the browser model is unavailable.
