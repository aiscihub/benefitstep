# Chrome Web Store listing — other languages

The store takes each language's title and summary from the package (`_locales/<code>/messages.json`); they cannot be typed into the dashboard. The detailed description is entered in the dashboard: open **Store listing**, choose the language in the language menu, and paste the text below. The menu offers a language only after a package that contains its `_locales` folder has been uploaded: 0.3.10 or later for Simplified Chinese and Spanish, 0.3.11 or later for Traditional Chinese and Vietnamese.

The English listing is unchanged; see `LISTING.md`.

## 简体中文 (zh_CN)

Title (from the package): BenefitStep — 福利申请助手

Summary (from the package): 准备 CalFresh（食品补助）和 Medi-Cal（白卡）申请草稿：在本地识别文件、核对材料，并下载 PDF。

Detailed description:

```text
BenefitStep 帮助加州家庭更轻松地准备 CalFresh（食品补助）和 Medi-Cal（白卡）申请材料。

支持中文界面、快速资格预查、本地识别工资单和房租收据等文件、核对申请信息，并生成官方 PDF 表格草稿。也支持续期和定期报告的材料准备。

所有个人资料在本地处理，无需上传至开发者服务器。不代表政府官方机构，不提供最终资格认定，也不代替正式申请提交。
```
