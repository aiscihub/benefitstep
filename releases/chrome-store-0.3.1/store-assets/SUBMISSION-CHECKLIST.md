# Submission checklist

Upload only `benefitstep-0.3.1-chrome-store.zip`. Do not upload the repository or the store-assets folder as extension code.

## Included
- Manifest V3 ZIP, manifest at root, description, version 0.3.1 and local 16/32/48/128 PNG icons.
- Local runtime, policy engine, models, official PDF templates and standard fonts.
- Listing text, privacy-policy HTML, reviewer instructions and checksums.
- Store images are included alongside this checklist.

## Publisher still needs to do
- Register/verify the developer account and enable two-step verification.
- Host privacy-policy.html at a publicly reachable URL and put that URL in the dashboard.
- Supply the developer identity, support contact and any dashboard-required account details.
- Review listing text, data handling declarations and images; choose distribution and regions.
- Submit for review. This package has not been uploaded or approved.

Independent PDF field/branch review, desktop/print validation and two reviewer sign-offs remain open project requirements. They are not claimed complete by packaging or store submission. Recommended initial audience: trusted testers using fictional data.
