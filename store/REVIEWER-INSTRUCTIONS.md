# Reviewer instructions

No login, subscription, test credentials or backend server is required.

1. Install the extension; pin BenefitStep and click its toolbar icon to open the sidebar.
2. On Quick check, choose California residence, household size 3 and an income range. Click See my results; these are preliminary reference checks.
3. Open Document and select Try AI demo with fictional documents. Three bundled documents are classified locally. No browser AI model download is needed for this demo.
4. Open Review. The additional fictional household questionnaire is explicitly separate from AI extraction. Confirm the reviewed details.
5. Open Application. Choose Generate CalFresh package (CF285), inspect/edit populated fictional answers, confirm, then Generate filled application draft.
6. Inspect the original form pages. Download filled PDF or Download application package. The package includes the unsigned PDF, answers and unresolved-item checklist. Demo PDFs are marked FICTIONAL DEMO — DO NOT SUBMIT.
7. Repeat for Medi-Cal (CCFRM604). Generation does not submit anything to an agency.
8. Privacy > Clear my work clears temporary data. Downloads already saved to the user's device are not deleted.

Only the sidePanel permission is requested. No host permissions, content scripts, account storage, remote executable code or analytics are used. Official-source links open external sites only on user action. The bundled classifier and local reader work without the optional Chrome built-in model. Scans and unrecognized formats may need manual entry.

Known preview limits: partial form coverage and independent mapping review pending; no automated signatures/consents, full eligibility decision, BenefitsCal autofill or agency submission.
